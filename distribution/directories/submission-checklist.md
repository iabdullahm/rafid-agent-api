# Manual submission checklist

1. Deploy the current commit and verify /api/v1/discovery, /api/v1/capabilities, /openapi.json, /mcp, /robots.txt and /sitemap.xml.
2. Verify runtime x402 status, Base network, USDC asset, facilitator and payTo without copying secrets.
3. Confirm the public domain and repository ownership in each directory account.
4. Submit the prepared MCP, A2A and x402 metadata and record external approval links.
5. Re-run this pack generator whenever the canonical registry changes.
